## Findings that matter for v0.2

1. **No SPA fallback in the server.** `StaticFiles(html=True)` returns 404 for `/call`, `/careers`, `/tickets/...` on a hard load, and `/office` is also a static mount for the Phaser assets (`app.py:94`), so loading `/office` as a URL will not reach the React route. In-app navigation works (I used `pushState`). A mini window pointing at `http://127.0.0.1:<port>/call` would 404 today; this spike therefore serves the placeholder from Tauri's own `ui/call.html`. For v0.2, add an index.html fallback in the server and move the asset mount (e.g. `/assets/office`), or use a hash route. Owner: server/web, not changed here.
2. Page-load log shows the main window ends up on `/careers` because the app redirects before onboarding; unrelated to the shell.
3. Job Object assignment happens right after spawn, not at creation, so a grandchild started in the first microseconds could escape. In the runs it did not (`job assign ok=true`; all three processes died). A suspended-start spawn would close the gap if it ever matters.
4. Port handshake uses "pick a free port, pass `--port`" (as the brief said), not the stdout `PORT=` handshake from research §1.1. Small race between releasing and rebinding the port; acceptable locally.
5. The server was started with all stdio null; server logs are lost. v0.2 should redirect stdout/stderr to `<home>/.data/server.log`.
6. Page remote URL gets no Tauri IPC (the capability applies only to `main` local pages and `call`); good default, since the page does not need it.

## Not verified

- Tray menu clicks, tooltip text and the call window opening: need real clicks, which are off limits (no OS input). The code compiles and the tray builds without error (no failure logged); tooltip content is unchecked.
- Global shortcut: `ptt.log` was not created because no key was pressed; registration did not fail at startup (a failed registration would have errored at startup; the app ran, but the log was not checked for it). Luigi tests by hand in S6.
- Toast: requires the installed NSIS build (app name vs PowerShell); the installer was built, not run.
- Phaser fps vs Chrome, as above.
