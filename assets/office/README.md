# Office art

Everything here and in `web/public/office/` is **generated by Offer Letter's
own scripts** in `tools/pixel/`: no LimeZu, Kenney or other third-party
pixels (decision D3).

**Licence: CC0 1.0** (public domain dedication). The palette ("Kiln 32",
`tools/pixel/palette.py`) was designed for this project and is CC0 too.

## What gets generated

| File (under `web/public/office/`) | Made by | What it is |
|---|---|---|
| `tileset.png`, `tileset.tsj` | `gen_tileset.py` | 16×16 tiles in a Tiled JSON tileset. Each tile has `name`, `layer`, `collides` (and `seat` on chairs) properties. Racks, monitors, the coffee machine and the server-room door lamp have Tiled animations. |
| `kilnworks.tmj` | `build_map.py` | 48×30 Tiled map with the tileset embedded. Layers: `floor`, `walls`, `furniture_below`, `furniture_above` (drawn over characters), and the `poi` object layer (desks, meeting seats, server-room spots, coffee, door, zones). |
| `characters/<id>.png` | `gen_characters.py` | One sheet per Kilnworks teammate plus `player_default`. 16×32 frames, 7 columns (idle, walk 1–4, sit, type) × 4 rows (down, left, right, up). `kenji_focus.png` has his headphones on. |
| `characters/layers/*.png`, `characters.json` | `gen_characters.py` | The same characters as separate layers painted in KEY colours, plus ramps and recipes, so the avatar picker can build the player from the same parts (see `web/src/office/avatar.ts`). |
| `bubbles.png`, `marker.png`, `font3x5.png` | `gen_characters.py` | Status bubbles (typing, focus, alert, ask, talk, coffee), the player marker, a 3×5 pixel font for name tags. |

Also in this folder: `contact-sheet.png` (every object, tile, character
frame and avatar option at 3×) and `screens/` (headless screenshots of the
real scene).

## Regenerate

From the repo root, PowerShell or Git Bash:

```
uv run --with pillow --with pytiled-parser python tools/pixel/build_all.py
```

That runs, in order: `gen_tileset.py`, `build_map.py`, `gen_characters.py`,
`contact_sheet.py`, `check_map.py` (an independent parse with
pytiled-parser, gids in range, every POI walkable and reachable from the
door, and every generated PNG using only Kiln 32 colours). Output is
deterministic: running it twice gives byte-identical files.

## Screenshots and checks (headless, no real-desktop capture)

The harness in `tools/pixel/preview/` serves the real `web/src/office/` code
and `web/public/` assets with its own pinned phaser/easystarjs/react.

```
cd tools/pixel/preview
pnpm install
pnpm exec tsc --noEmit -p tsconfig.json   # strict typecheck of web/src/office
node check.mjs                            # functional checks in headless Chromium
node smoke-build.mjs                      # production bundle (vite build) loads the office
node shots.mjs                            # writes assets/office/screens/*.png
node rooms.mjs                            # 3x room close-ups -> assets/office/screens/rooms/
node gif.mjs                              # standup.gif (needs uv for the Pillow step)
pnpm dev                                  # http://127.0.0.1:5180 (toolbar: modes, camera, remount)
```

Screens: `00-arrival-follow.png` is the default first view (follow camera,
3×, the player arriving under the sign); `01`–`04` are the four scene modes
over the whole map at 2×; `05` catches the team mid-walk to standup;
`06`/`07` are 3× close-ups by day and night.

## Changing the art

- A new piece of furniture: add a drawing function in `gen_tileset.py`, then
  `REG.obj("name", canvas, layout)` where each layout letter says the layer and
  collision of that cell (`B` below+solid, `a` above+walkable, `S` seat,
  `W` wall, `F` floor). Place it in `build_map.py` with `m.place("name", x, y)`.
- A new hairstyle or outfit: add ASCII parts to `char_parts.py` (role letters
  are listed at the top of that file). It shows up in `characters.json`
  options and the contact sheet automatically.
- Keep to the palette. Light comes from the top-left; furniture gets a 1-px
  ink outline.
